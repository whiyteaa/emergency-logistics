# 应急物流仿真平台 · 全屏地图背景 + 悬浮玻璃面板改版方案

还原点已创建：`还原点-应急物流仿真平台(15).html`（回滚时直接覆盖回来即可）。改动继续在 `应急物流仿真平台 (15)-优化版.html` 上进行。**所有仿真逻辑（10步编排、调度算法、语音、离线兜底）零改动，纯布局/主题改造。**

## 一、整体布局改造

**现状**：三栏白卡片布局，地图被限制在中栏卡片内。
**目标**：地图全屏铺满作为整页背景，所有 UI 悬浮其上。

1. **地图层**：`#mapWrap`（含 `#mapLeaflet` + `#mapFallback`）从中间面板移出，改为 `position:absolute; inset:0; z-index:0` 全屏底层。保留原 id/类名（`fallback`、`dark-tiles` 切换机制原样工作），CSS 直接覆盖 `.map-wrap` 定位即可，JS 几乎不动。
2. **悬浮层**：`.app` 保持 `54px顶栏 / 1fr主区 / 底栏` 网格，改为透明悬浮在地图上（z-index 高于地图）：
   - 顶栏：通栏深蓝玻璃条（logo、标签、预警徽标、时钟、静音保留）
   - 主区仍是三列网格：**左面板（外部系统调度编排）**、**中间透明区**、**右面板（仿真控制台）**，两侧为深蓝半透明玻璃卡片（约 360px 宽、圆角、亮边框、backdrop-blur），中间列完全透空露出地图
   - 底栏：时间轴 + KPI 通栏玻璃条
3. **中间聚焦区**（满足"调度跳转与路径规划聚焦中间展示"）：
   - 新建 `.center-zone`（中间列内的透明容器，`pointer-events:none` 让地图可拖拽，子控件单独恢复事件）
   - 地图 UI 挂件全部移入并重新排布：图层切换（左上）、阶段徽标（右上）、需求/路线浮卡（左下/右下）、图例（底部居中，原有位置）、方案比选弹窗（居中）、实景卡片（顶部居中，避让两侧面板）
   - `startTransport` 的 `flyToBounds` padding 改为运行时读取左右面板实际宽度动态计算，保证路线动画完整落在中间可视区
   - 步骤聚焦 `flyTo` 以视口中心为目标（左右面板近似对称，视口中心≈中间区中心），不需要额外偏移

## 二、深蓝科技大屏主题（对齐参考截图配色）

当前浅色主题在全屏地图上会显得浑浊，统一改为深蓝玻璃风格：

1. **`:root` 变量集中换肤**：深蓝底色、`--card`→`rgba(10,24,48,.78)`、亮色文字、半透明描边；强调色（蓝/青/绿/橙/红）提亮保留
2. **逐组件深色化**（约40处）：系统卡、日志条、任务卡、控制台按钮/选项/下拉框、KPI 卡、时间轴节点、浮卡、图例、方案弹窗、实景卡片、地图徽标等 → 半透明深色块 + 亮色文字；日志的"中断/回报"色块改为暗色半透明底+亮色文字
3. **地图本体协调**：矢量模式下瓦片加 CSS 滤镜调暗（复用现有 `dark-tiles` 类钩子：`filter:brightness(.8) saturate(.85)`），卫星模式保持原色——两种图层都与深色 UI 融合；地图图钉标签/图标底色改深色半透明
4. **离线兜底 SVG**：两套配色统一改为深色底（矢量=深蓝调、卫星=橄榄绿调），与整体主题一致
5. **body 背景**：深蓝渐变（瓦片加载前/离线时不再是白底）

## 三、必要的 JS 微调（不改逻辑）

1. `startTransport` 动态 padding（读取面板实际宽度）
2. 新增 window resize → `map.invalidateSize()`（地图从卡片内变为全屏，需要跟随窗口）
3. `showMapToast` 位置下移避开顶栏（z-index 提高）
4. 离线 SVG 配色常量微调（深色底）
5. 移动端媒体查询适配（小屏面板改为上下堆叠悬浮）

## 四、实施顺序

1. HTML 结构调整（地图移出、center-zone 组装、挂件迁移）
2. 全屏地图 CSS + 悬浮层网格
3. 深色主题变量 + 组件级换肤（最大工作量，逐块进行）
4. JS 微调（padding/resize/toast/兜底配色）
5. **浏览器实测验收**：常态页、卫星切换、启动仿真后的聚焦跳转（确认目标点居中）、投送路线动画（确认在中间区完整可见）、方案弹窗、实景卡、离线兜底模式，每步截图像素级检查

## 风险与回滚

- 改动集中在 CSS/HTML 结构，JS 逻辑不动，功能回归风险低
- 每个大步骤后语法校验；最终完整跑一遍仿真流程验证
- 任何问题用还原点文件直接覆盖回滚
